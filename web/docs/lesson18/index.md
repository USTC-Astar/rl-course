## 1. 蒙特卡洛：等整局结束，用全真材料算账

<ConceptDiagram kind="mc-vs-td" />

**蒙特卡洛方法（Monte Carlo Method, MC）**的学习规则朴素到极点：跑完一整局，把实际拿到的折扣回报 $G_t$ 直接当作 $V(s_t)$ 的学习目标：

$$
V(s_t) \leftarrow V(s_t) + \alpha\big(\, G_t - V(s_t) \,\big)
$$

只依赖**真实经历**，不依赖任何价值估计——所以它**无偏**（目标里没有会被带错的成分）；但整条轨迹的所有随机性都进入 $G_t$，**方差大**，而且必须等到回合结束才能更新。

### 真实实验：MC 估计会收敛到真值吗？

在 6×6 网格上让**均匀随机策略**跑 4000 回合，用首访 MC 估计三个状态的价值，同时用第 0 课的动态规划**精确评估同一个随机策略**作为真值（`scripts/generate_td_variants.py`）：

| 状态 | MC 估计（4000 回合） | 随机策略真值 | 最优价值（对照） | 被访问次数 |
| --- | ---: | ---: | ---: | ---: |
| 起点 $(5,0)$ | $-9.478$ | $-9.454$ | $+5.563$ | 4000 |
| $(0,0)$ | $-8.975$ | $-8.959$ | $+7.774$ | 722 |
| $(5,5)$ | $-8.548$ | $-8.491$ | $+7.774$ | 242 |

读表结论有两条：

1. **估计收敛**：访问 4000 次的起点，估计与真值只差 $0.024$；访问只有 242 次的 $(5,5)$ 差 $0.057$——采样越少，残差越大，这就是方差的具体形状。
2. **策略天差地别**：同样这个格子，随机策略下价值约 $-9.5$（大概率耗尽 100 步拿 $-10$），最优策略下是 $+5.56$。"价值"永远绑着"策略"，脱离策略谈价值没有意义。

## 2. SARSA：和 Q 学习只差一个符号

第 1 课的 Q 学习目标用下一状态的**最大** Q 值：

$$
\text{Q 学习：}\quad \text{目标} = r + \gamma \max_{a'} Q(s', a')
$$

**SARSA（State-Action-Reward-State-Action 的缩写，就是更新元组的五个字母）**把 $\max$ 换成**行为策略实际选出的下一个动作**：

$$
\text{SARSA：}\quad \text{目标} = r + \gamma\, Q(s', a')
$$

$a'$ 是智能体**下一步真会做**的动作（由 ε-贪心选出的那个，可能是随机探索）。这个差别看似微小，含义完全不同：

- Q 学习评估的是"**如果**以后都走最优，这一步值多少"——它学的是最优策略，不管自己现在怎么探索（**异策略，Off-Policy**）；
- SARSA 评估的是"**按我现在这套带探索的行为**，这一步值多少"——它学的是当前行为策略本身（**同策略，On-Policy**）。

**手算对比**：设 $\gamma=0.9$，下一状态有三个动作 $Q(s') = [1,\ 5,\ 2]$，ε-贪心以 $\frac{\varepsilon}{3}$ 概率选每个动作：

| | 目标计算（$r=0$） | 数值 |
| --- | --- | ---: |
| Q 学习 | $0.9 \times \max(1,5,2)$ | $4.5$ |
| SARSA（这次探索选了第 1 个动作） | $0.9 \times 1$ | $0.9$ |
| SARSA（这次贪心选了第 2 个动作） | $0.9 \times 5$ | $4.5$ |

同样的经历，Q 学习永远按 4.5 记账；SARSA 有时按 4.5、有时按 0.9 记账——它的价值表里带着"探索会闯祸"的风险意识。

### 这如何变成不同的性格

在悬崖寻路类问题里差异最出名：贴着悬崖走的路最短、贪心价值最高。

- **Q 学习**学到贴崖最优路线，但执行时 ε 探索偶尔把它推下悬崖——训练期回报抖动大；
- **SARSA**学到离悬崖远一两条的路——既然我一定会随机乱走，那就选一条"乱走也安全"的路。

两者没有绝对优劣：要**最优策略且探索可关到很小**时 Q 学习更合适；**探索无法避免、要求行为稳健**时 SARSA 更合适。

## 3. 同策略 vs 异策略：全课程最常回收的一对概念

| | 同策略（On-Policy） | 异策略（Off-Policy） |
| --- | --- | --- |
| 代表 | SARSA、REINFORCE、A2C、PPO | Q 学习、DQN、SAC、TD3 |
| 数据要求 | 必须由当前（或非常接近的）策略产生 | 可复用任意旧策略、别的策略甚至人类演示的数据 |
| 优点 | 评估与行为一致，训练稳定 | 样本效率高，能利用回放池和历史数据 |
| 代价 | 数据用完即弃，样本效率低 | 目标与行为脱节，需要额外机制（目标网络、重要性采样）防跑偏 |

一个快速判别法：**看更新目标里的未来项——写 $\max$ 或独立目标网络的，多半是异策略；写"自己实际选的动作"的，是同策略。**第 5 课 PPO 的"旧经验只能有限复用"、第 7 课 SAC 的"长期复用旧经验"、第 16 课的"离线数据只能配异策略"，全都建立在这对概念上。

## 4. 真实对照训练

同一随机种子（seed=11）、同一环境、$\varepsilon=0.1$、$\alpha=0.15$、$\gamma=0.95$，各训练 800 回合（`src/rl_learning_lab/td_variants.py`）：

| | 后 100 回合成功率 | 后 100 回合平均奖励 |
| --- | ---: | ---: |
| SARSA | $100\%$ | $8.53$ |
| Q 学习 | $99\%$ | $8.25$ |

在本网格世界（陷阱不在最优路线上）两者最终都稳定到达终点；SARSA 的行为奖励略高，因为它的价值表把"探索可能撞陷阱/绕路"计入后，行为策略整体更保守。这不是"谁更强"的结论，而是"目标函数不同，产物不同"的具体例子。

核心对照代码（`src/rl_learning_lab/td_variants.py`，两行注释就是全部差别）：

```python
if use_sarsa:
    next_action = choose_action(q_table, next_state, epsilon, rng)
    target = reward + gamma * q_table[next_state, next_action]   # 实际会做的动作
else:
    target = reward + gamma * float(q_table[next_state].max())   # 假设以后都走最优
q_table[state, action] += alpha * (target - q_table[state, action])
```

## 7. 常见误区

- **"MC 无偏所以比 TD 好"。** 无偏只说明平均方向对；方差大意味着同样数据量下收敛更慢，且必须等到回合结束。
- **"SARSA 的 a′ 是最优动作"。** 恰恰相反：$a'$ 是行为策略（含探索）实际选出的动作，这是它与 Q 学习的全部区别。
- **"同策略就是没有探索"。** ε-贪心的 SARSA 是同策略——探索本身就是行为策略的一部分。
- **"价值表是环境的属性"。** 价值永远绑定策略：随机策略下起点值 $-9.5$，最优策略下 $+5.6$，同一格子、同一个世界。

## 10. 本课只需要记住这些

- MC 等整局、用真实回报：无偏、方差大；TD 走一步、用自举估计：有偏、方差小。
- SARSA 与 Q 学习只差"下一项取实际动作还是取 max"。
- 同策略数据即采即用，异策略可复用旧数据——这条分界线贯穿后面所有课程。
- 价值表描述的是"某个策略下"的世界，不存在脱离策略的价值。

第 8 课的 n 步回报会在 MC 与 TD 这两个极端之间搭一座连续的桥；第 19 课把探索从"ε-贪心"一门手艺扩展成一族方法。
