## 1. 先把强化学习想成“自己练走迷宫”

假设你第一次进入一栋没有地图的大楼，要找到出口：

1. 你站在某个路口，这就是**状态（State）**。
2. 你可以向左、右、前、后走，这就是**动作（Action）**。
3. 走进死胡同浪费时间，得到负面反馈；找到出口得到正面反馈，这就是**奖励（Reward）**。
4. 你把“这个路口向右走比较好”记在心里，这就是价值经验。
5. 下次来到相似路口，你更愿意选择高分方向，这就是**策略（Policy）**。

执行动作的机器人叫**智能体（Agent）**，给出新状态和奖励的世界叫**环境（Environment）**。它们不断循环：

`观察状态 → 选择动作 → 环境变化 → 得到奖励 → 更新经验`

## 2. 马尔可夫决策过程到底是什么？

强化学习常用**马尔可夫决策过程（Markov Decision Process, MDP）**描述问题。名字很长，核心只有一句话：

> 如果当前状态已经包含做决定需要的关键信息，那么预测下一步时，不必重新翻阅全部历史。

例如，网格机器人的状态就是当前位置。只要知道它现在在第几行第几列，就能判断向右是否撞墙；不必知道它五分钟前走过哪里。

::: warning “只看当前状态”不等于“忘记过去”
如果当前观测没有包含速度，CartPole 只看一张静止图片就无法判断杆子正往哪边倒。此时观测不完整，需要加入速度、历史帧或记忆网络。
:::

## 3. Q 值：给“处境 + 动作”打长期分

**动作价值函数（Action-Value Function）**通常写成 `Q(s,a)`：

- `s` 是当前状态。
- `a` 是准备采取的动作。
- `Q(s,a)` 是从这里这样做以后，未来累计奖励大概有多好。

把它想成餐馆经验表：

| 处境 | 动作 | 经验分 |
| --- | --- | ---: |
| 工作日中午 | 去楼下快餐店 | 7.5 |
| 工作日中午 | 去远处排队网红店 | 3.0 |
| 周末晚上 | 去网红店 | 8.0 |

“同一家餐馆”在不同处境下价值不同，所以 Q 值必须同时绑定状态和动作。

## 4. 一次 Q 学习更新怎样计算？

**Q 学习（Q-Learning）**使用下面的更新：

<div class="formula-box">
  <span class="formula">Q(s,a) ← Q(s,a) + α · [r + γ max Q(s′,a′) - Q(s,a)]</span>
  方括号里的部分表示“新目标和旧估计差多少”，学习率 α 决定这次改多少，折扣因子 γ 决定多重视未来。
</div>

假设：

- 原来的 `Q(s,a)=2`；
- 走一步得到奖励 `r=-0.1`；
- 下一状态最好动作价值 `max Q(s′,a′)=5`；
- 学习率 `α=0.5`；折扣因子 `γ=0.9`。

<ol class="step-list">
  <li>先算新目标：`-0.1 + 0.9 × 5 = 4.4`。</li>
  <li>再算判断误差：`4.4 - 2 = 2.4`。</li>
  <li>只吸收一半误差：`0.5 × 2.4 = 1.2`。</li>
  <li>新 Q 值：`2 + 1.2 = 3.2`。</li>
</ol>

这像你原来给一家店打 2 分，新体验说明它可能值 4.4 分，但你不会因为一次体验立刻完全改成 4.4，而是先调到 3.2。


<div class="algorithm-box">

**算法：表格型 Q 学习（ε-贪心）**

1. **初始化**：Q 表全部置 0；ε ← 1.0。
1. 每个回合：状态 s ← 起点。
1. 循环直到终止或超过步数上限：以概率 ε 随机选动作（探索），否则选 Q(s,·) 最大的动作（利用）。
1. 执行动作，观察 r、s′、done；目标 = r + γ·(done ? 0 : max Q(s′,·))。
1. Q(s,a) ← Q(s,a) + α·(目标 − Q(s,a))；s ← s′。
1. 回合结束后 ε 缓慢衰减（如 ×0.997，下限 0.05），回到第 2 步。

</div>

## 5. 探索与利用为什么必须同时存在？

**ε-贪心策略（Epsilon-Greedy Policy）**规定：

- 以概率 `ε` 随机试一个动作，叫探索。
- 以概率 `1-ε` 选择当前 Q 值最高动作，叫利用。

如果从第一回合开始就只利用，机器人可能因为偶然走到一条很长的安全路线，就再也不尝试更短路线；如果永远大量探索，它又会一直像新手一样乱走。

## 6. 奖励设计怎样悄悄改变行为？

本项目的奖励大致是：终点大额加分，陷阱大额扣分，撞墙扣分，每走一步也扣少量分。

每步惩罚解决的是“**到达终点就算成功，还是要尽快到达**”的问题：

- 没有步数成本：走 10 步和走 80 步可能都得到同样总分。
- 有小额步数成本：绕路越多，累计损失越大，最短路线更有吸引力。

::: danger 奖励不是越复杂越好
奖励规则太多可能出现“钻空子”。例如只奖励速度，机器人可能高速撞墙；只惩罚能耗，它可能原地不动。先写清真正目标，再逐项检查奖励是否与目标一致。
:::

## 7. 对应的可运行代码

核心训练代码位于 `src/rl_learning_lab/gridworld.py`。下面保留了真正影响学习的部分：

```python
for episode in range(config.episodes):
    state = env.reset()

    for _ in range(env.config.max_steps):
        # 训练早期需要探索，否则机器人可能被第一条偶然路线困住。
        action = choose_action(q_table, state, epsilon, random_generator)
        next_state, reward, done = env.step(action)

        # 终点之后没有未来价值，所以结束状态的 bootstrap 必须为 0。
        next_best_value = 0.0 if done else float(q_table[next_state].max())
        target = reward + config.discount_factor * next_best_value
        error = target - q_table[state, action]
        q_table[state, action] += config.learning_rate * error

        state = next_state
        if done:
            break
```

运行本课：


## 9. 常见误区

- **把奖励当成动作标签。** 环境只说结果好坏，没有告诉机器人刚才哪一步一定正确。
- **认为 Q 值等于即时奖励。** Q 值包含从当前动作开始的未来累计收益。
- **认为训练回报必须单调上升。** 探索和随机性会制造波动，应观察移动平均和独立评估。
- **终止状态继续加未来价值。** 到达真正终点后应停止 bootstrap，否则会凭空制造未来奖励。

## 10. 动手练习

1. 把每步奖励从 `-0.1` 改成 `0`，比较路线长度。
2. 把探索率固定为 `0`，观察不同随机种子下是否容易卡住。
3. 把折扣因子调低到 `0.5`，思考机器人为什么更“短视”。

## 12. 本课只需要记住这些

- 强化学习循环是“观察—行动—反馈—更新”。
- Q 值评价的是某状态下某动作的长期价值。
- Q 学习用即时奖励和下一状态最佳价值修正旧估计。
- 探索负责发现新可能，利用负责兑现已有经验。
