# 第 16 课：离线强化学习

<div class="lesson-lead">
在线强化学习可以发现不确定动作后亲自试一次。离线强化学习只能看一份固定历史数据，不能再向环境提问，因此网络对“没见过的动作”胡乱乐观会特别危险。
</div>

## 本课主线

> 离线强化学习的核心矛盾是：既想超过数据收集策略，又不能离开数据覆盖范围太远；保守方法宁可低估陌生动作，也不相信无证据的高 Q 值。

## 1. 离线 RL 与普通回放池有什么差别？

**离线强化学习（Offline Reinforcement Learning, Offline RL）**训练期间只有固定数据集：

`D={(s,a,r,s′,done)}`

数据由某个或多个**行为策略（Behavior Policy）**产生。训练算法不能执行新策略去采样，也不能发现错误后补数据。

SAC 虽然也从回放池学习，但仍会持续与环境交互，新策略访问的新状态会进入回放池。这是关键差别。

## 2. 分布外动作为什么会被凭空高估？

假设医疗数据中，某类病人几乎只接受剂量 1～3。Q 网络却能对剂量 0～10 全部输出数值。

对于剂量 8，训练数据没有事实约束，神经网络只是外推。它可能偶然输出很高 Q 值；策略看到高值后偏偏选择剂量 8，却没有在线试错机会及时纠正。

这种训练数据分布与新策略访问分布不一致叫**分布偏移（Distribution Shift）**，对数据外动作的错误推断常称**外推误差（Extrapolation Error）**。

类比只看过城市道路驾驶录像，却让模型判断冰面高速转弯。网络一定会输出一个数，但“有输出”不等于“有证据”。

## 3. 只做行为克隆不就安全吗？

**行为克隆（Behavior Cloning, BC）**直接模仿数据中的动作，通常更安全简单，但无法利用奖励区分好行为和坏行为。

如果数据来自普通驾驶员：

- 行为克隆学平均驾驶水平；
- 离线 RL 希望从数据中识别哪些选择回报更高，组合出更好的策略。

难点是改进不能走得太远。离线 RL 位于“只模仿”和“自由优化”之间。

## 4. 保守 Q 学习怎样压低陌生动作？

**保守 Q 学习（Conservative Q-Learning, CQL）**加入一项正则：

<div class="formula-box">
  <span class="formula">L_CQL = log Σₐ exp Q(s,a) - Q(s,a_data)</span>
  第一项看到所有动作中的高 Q，第二项保留数据动作 Q。最小化后，会压低未被数据支持却虚高的动作。
</div>

直觉：网络如果给某个数据外动作很高分，`logsumexp` 会显著增大；除非这个动作真的在数据中被执行并得到支持，否则没有第二项帮它抵消。

总评论家损失可写为：

`L = Bellman误差 + α × L_CQL`

α 越大越保守，但过大时策略可能退化为近似行为克隆，失去改进能力。

## 5. 数据覆盖率决定了能力上限

数据集中没有的信息，算法无法可靠恢复：

- 从未到过的状态，没有转移证据；
- 从未执行的动作，没有结果证据；
- 奖励记录错误，价值学习也会跟着错误。

因此离线 RL 项目的第一步不是选算法，而是做数据审计：状态覆盖、动作分布、终止原因、奖励尺度、缺失值和不同来源策略。

## 6. 怎样离线评估新策略？

不能只看训练 Q 值，因为 Q 网络正是可能过度乐观的来源。

常见方法：

- 留出数据集上的拟合和行为接近程度；
- **离策略评估（Off-Policy Evaluation, OPE）**，如重要性采样；
- 拟合环境模型进行有限模拟；
- 小流量、受控、安全约束下在线验证；
- 多种估计方法交叉检查并给置信区间。

医疗和工业场景不能因为离线指标高就直接全量部署。

## 7. 对应的可运行代码

核心位于 `src/rl_learning_lab/advanced_lessons.py`：

```python
def conservative_q_regularizer(q_values, dataset_actions):
    # q_values: [批次, 动作数]
    dataset_q_values = q_values.gather(
        1,
        dataset_actions.unsqueeze(1),
    ).squeeze(1)

    # logsumexp 平滑关注所有动作中的高值；减去数据动作值后，
    # 会重点惩罚“数据没支持却被网络抬得很高”的动作。
    return (torch.logsumexp(q_values, dim=1) - dataset_q_values).mean()
```

## 9. 离线数据有哪些常见类型？

- 专家数据：质量高但覆盖窄。
- 随机数据：覆盖广但高回报样本少。
- 混合质量数据：最常见，也最考验算法区分能力。
- 多策略历史日志：覆盖较广，但策略版本和环境可能变化。

理想数据集不是只包含成功轨迹。适量失败和边界情况能让模型知道什么不该做。

## 10. 常见误区

- **离线 RL 就是把 SAC 的环境关掉。** 没有新数据纠错后，分布外高估会成为核心风险。
- **数据越多一定越好。** 大量重复、偏置或错误数据可能比少量高质量数据更糟。
- **CQL α 越大越安全。** 过度保守会失去策略改进能力。
- **训练 Q 值高说明策略好。** 离线场景最需要怀疑无证据的高 Q。

## 13. 本课只需要记住这些

- 离线 RL 只使用固定数据集，训练时不能补采样。
- 分布外动作的 Q 值缺少事实约束，容易虚高。
- CQL 用保守正则压低数据外动作价值。
- 数据覆盖和可靠离线评估决定最终能力边界。
