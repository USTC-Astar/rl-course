## 易混淆概念对照

| 一对概念 | 一句话区分 |
| --- | --- |
| 奖励 $r$ vs 回报 $G$ | 奖励是单步得分；回报是往后所有折扣奖励的累计 |
| 价值 $V$ vs 动作价值 $Q$ | $V$ 评价处境，$Q$ 评价“处境 + 具体动作” |
| 优势 $A$ vs TD 误差 $\delta$ | $\delta$ 是一次采样的“意外”，$A$ 是这个意外的期望 |
| 策略 $\pi$ vs 价值函数 | 策略回答“做什么”，价值函数回答“这样做值多少” |
| 探索 vs 利用 | 探索收集信息，利用兑现已知最优 |
| on-policy vs off-policy | 前者数据必须来自（接近）当前策略，后者可复用任意旧数据 |
| 裁剪系数 $\varepsilon$ vs 探索率 $\varepsilon$ | 两个毫不相干的希腊字母恰好同名：前者限 PPO 更新幅度，后者管探索 |
| 概率比裁剪 vs 梯度裁剪 | 前者裁目标函数里的比值，后者裁参数梯度长度 |
| 熵 vs 方差 | 熵衡量策略的随机性（探索），方差衡量回报估计的波动（学习噪声） |
