# 第 19 课：探索方法进阶——比"随机乱试"更聪明的试错

<div class="lesson-lead">

## 本课主线

> 探索的本质是信息收集。随机探索不看信息，UCB 按"还没试准的地方"下注，汤普森按"世界可能的样子"下注，好奇心按"还没见过的地方"下注——收集信息的依据越具体，浪费越少。

## 1. 先定义"探索浪费了多少"：遗憾

<ConceptDiagram kind="exploration-map" />

**多臂赌博机（Multi-Armed Bandit）**是探索问题的最小模型：$k$ 个动作各有一个未知的成功概率 $p_i$，每步选一个，得 1 或 0。它没有状态转移——纯纯的"该试谁"问题。

衡量探索好坏的标准量是**遗憾（Regret）**：如果每步都选真正的最优臂，期望得 $\max_i p_i$；实际策略平均每步得 $\bar r_t$。累计遗憾：

$$
R_T = \sum_{t=1}^{T} \left(\max_i p_i - \bar r_t\right) = T \max_i p_i - \sum_{t=1}^{T} \bar r_t
$$

**数字代入**：最优臂 $p^*=0.7$，某策略 2000 步累计平均得分 1330，则 $R_{2000} = 0.7 \times 2000 - 1330 = 70$。遗憾越小，说明试错路上"明知不好还在试"和"该转正没转正"的浪费越少。

遗憾好在哪里？它把"探索"从形容词变成可计算、可比较的数字——这正是本课实验的纵坐标。

## 2. ε-贪心的账：浪费在哪里

ε-贪心每步以 $\varepsilon$ 概率均匀随机选臂。即使已经**完全确定**谁最好，它仍以 $\varepsilon \cdot \frac{k-1}{k}$ 的概率选到差臂——这部分浪费**不随时间减少**。这是它的设计缺陷，也是它的优点：实现一行代码，且永不放弃纠错机会。

## 3. UCB：给"没试准的臂"加分

**上置信界（Upper Confidence Bound, UCB）**的决策规则：

$$
a_t = \arg\max_i \left[\ \bar Q_i + c\,\sqrt{\frac{\ln t}{N_i}}\ \right]
$$

**符号说明**：$\bar Q_i$ 是臂 $i$ 的当前平均奖励；$N_i$ 是它被选过的次数；$t$ 是总步数；$c$ 是探索系数。

后一项叫**乐观加分**：均值差不多时，**试得越少的臂加分越高**，从而优先被选。

**手算一遍**：臂 A 均值 0.62、被试 50 次；臂 B 均值 0.60、被试 5 次；当前 $t=100$、$c=0.5$：

$$
\text{A 的加分} = 0.5\sqrt{\frac{\ln 100}{50}} = 0.5\sqrt{\frac{4.605}{50}} = 0.5 \times 0.303 = 0.152 \ \Rightarrow\ \text{UCB}_A = 0.772
$$

$$
\text{B 的加分} = 0.5\sqrt{\frac{4.605}{5}} = 0.5 \times 0.959 = 0.480 \ \Rightarrow\ \text{UCB}_B = 1.080
$$

尽管 B 的均值更低，它"还没被试准"，UCB 选 B。选它一次后 $N_B$ 变 6，加分自动缩小——**不确定性被每一次尝试兑现成信息，加分随之衰减**。$\ln t$ 缓慢增长保证任何臂的加分不会永远归零：久未问津的臂 Eventually 会因为 $\ln t$ 累积而被重新检查。

::: warning c 是必须调的超参数
乐观过头 = 永远在试差臂；乐观不足 = 过早锁死。本课实验里同一个 UCB，$c=0.5$ 与 $c=2.0$ 的遗憾差 6 倍。
:::

## 4. 汤普森采样：从"信念"里抽一套世界

**汤普森采样（Thompson Sampling, TS）**换一种思路：不维护"每个臂的分数"，而是维护"每个臂的成功概率可能是多少"的**后验分布**。伯努利情形配**贝塔分布（Beta Distribution）**最方便：

- 初始信念：$\text{Beta}(\alpha=1, \beta=1)$（均匀分布，"什么都不知道"）；
- 臂被选后：成功则 $\alpha \leftarrow \alpha+1$，失败则 $\beta \leftarrow \beta+1$。

每步做两件事：

1. 从每个臂的后验里**各抽一个随机数**（相当于随机假想一套"世界真相"）；
2. 选假想世界里最优的臂。

**数字示例**：臂 X 的后验是 $\text{Beta}(8, 2)$（试了 9 次中 7 次——它多半不错，分布集中在 0.7 附近）；臂 Y 是 $\text{Beta}(2, 8)$（试了 9 次中 1 次——多半差，但还有一线可能是 0.4+ 的好臂）。某一步抽到 $X=0.65$、$Y=0.55$ → 选 X；偶尔 Y 会抽到 0.7 而 X 抽到 0.6 → 自动再给 Y 一次机会。**探索不再靠外部规则，而是信念不确定性的自然副产品**：信念越模糊的臂，抽样波动越大，被翻牌的概率越高。

## 5. 真实对照实验

10 臂伯努利赌博机（真实概率 $[0.7, 0.5, 0.45, 0.6, 0.2, 0.1, 0.35, 0.55, 0.15, 0.4]$，最优臂 $p^*=0.7$），每种策略跑 100 个随机种子取平均（`src/rl_learning_lab/exploration.py`）：

| 策略 | 2000 步累计遗憾 | 最后 200 步平均奖励 |
| --- | ---: | ---: |
| ε-贪心 ε=0.1 | $70.2$ | $0.665$ |
| ε-贪心 ε=0.05 | $44.0$ | $0.676$ |
| UCB $c=0.5$ | $49.8$ | $0.691$ |
| UCB $c=2.0$ | $299.3$ | $0.594$ |
| 汤普森采样 | $62.1$ | $0.696$ |

读表结论（都来自真实运行，种子固定可复现）：

1. **后期收敛**汤普森最好（0.696 已非常接近上限 0.7），UCB(c=0.5) 紧随其后；
2. **ε=0.05 好于 ε=0.1**：探索衰减得快一点，浪费就少——印证"探索应随信心下降"；
3. **UCB 对系数极其敏感**：$c=2.0$ 的遗憾是 $c=0.5$ 的 6 倍，激进乐观在这个"多个次优臂很接近"的问题上持续烧钱；
4. 没有万能冠军： regrets 排序（ε0.05 < UCB0.5 < Thompson < ε0.1 < UCB2.0）会随问题结构、步数预算变化。

## 6. 稀疏奖励：好奇心驱动探索

以上方法都假设"每个动作马上有反馈"。当奖励**极度稀疏**（例如机器人要在 1000 步后才知道任务成败，或电子游戏只有通关才得分），臂间的均值差异根本测不出来，探索需要新的依据：**去没见过的地方**。

**好奇心驱动探索（Curiosity-Driven Exploration）**的思路：训练一个"下一状态预测器"，用**预测误差**当**内在奖励（Intrinsic Reward）**：

$$
r^{\text{内在}}_t = \| \hat s_{t+1} - s_{t+1} \|
$$

总奖励 = 外在任务奖励 + 权重 × 内在奖励。预测不准 = 世界的新区域 → 值得去。**随机网络蒸馏（Random Network Distillation, RND）**是流行实现：冻结一个随机目标网络，训练另一个网络预测它的输出，预测误差大的状态视为"新奇"。

代价与坑：噪声电视机会让预测误差永远很高（智能体盯着雪花屏看不够）；内在奖励权重过大会让智能体变成"观光客"，完全不去做任务。它解决的是"奖励太稀、无从下脚"，不是"普通的探索不足"。

## 9. 常见误区

- **"探索策略越聪明越好"。** 每种依据都有代价：UCB 要臂计数（状态连续时没法直接用），汤普森要后验模型，好奇心要额外网络且怕噪声。ε-贪心仍是深度强化学习的默认选择，因为它和函数逼近、回放池结合最省事。
- **"UCB 的加分是奖励"。** 它只进决策公式，不进学习目标——别把它加进回报里。
- **"汤普森采样是随机策略所以不稳定"。** 它的随机性来自后验，随数据增长自动收窄；长期行为是确定地收敛到最优臂。
- **"好奇心奖励可以替代外在奖励"。** 它是补充不是替代；权重失衡后智能体会收集新奇而不完成任务。

## 12. 本课只需要记住这些

- 遗憾把探索浪费变成可计算、可比较的数字。
- UCB 按"不确定性"探索：加分 $\propto \sqrt{\ln t / N_i}$，试得少的优先。
- 汤普森按"信念"探索：从后验抽一套世界，选它眼里的最优。
- 奖励稀疏时才需要好奇心这类内在奖励；它有观光客风险。
- 探索方法的智能程度与额外维护成本成正比，没有免费午餐。
