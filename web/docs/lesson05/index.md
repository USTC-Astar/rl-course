## 1. 为什么策略不能一次改太多？

想象你正在高速开车：前方道路稍微向左弯，正确操作是小幅转动方向盘；如果因为“向左有利”就瞬间把方向盘打满，车辆会冲出道路。

策略更新也一样。某批数据只代表旧策略访问过的状态。如果更新一步后策略完全改变，它将去往数据中没有覆盖的新状态；原来的优势估计在那里未必可靠。

**近端策略优化（Proximal Policy Optimization, PPO）**中的“近端”可以理解为：新策略不要离旧策略太远。

## 2. 旧经验为什么会过期？

假设旧策略在某状态下：

- 向左概率 40%；
- 向右概率 60%。

它采样到“向右”并得到正优势。训练后新策略把向右概率改成 90%。同一条旧经验在两个策略下出现概率不同，不能假装它仍来自当前策略。

PPO 使用**重要性采样比率（Importance Sampling Ratio）**：

<div class="formula-box">
  <span class="formula">rₜ(θ) = π_new(aₜ|sₜ) / π_old(aₜ|sₜ)</span>
  比值大于 1 表示新策略更愿意选择这个动作；小于 1 表示更不愿意；等于 1 表示没有变化。
</div>

例如，旧概率 0.6，新概率 0.9，比例是 `0.9/0.6=1.5`。这意味着新策略选择该动作的倾向提高了 50%。

## 3. 裁剪目标怎样充当限速器？

PPO 的核心目标：

<div class="formula-box">
  <span class="formula">L_clip = min[rₜAₜ, clip(rₜ, 1-ε, 1+ε)Aₜ]</span>
  常用 ε=0.2，即把有效概率比限制在 0.8～1.2 附近。
</div>

分两种情况理解：

### 优势为正：这个动作值得鼓励

概率比从 1 增到 1.1，目标继续变好；增到 1.2，还能得到收益；增到 1.5，裁剪分支只按 1.2 计算，继续猛增概率不再带来额外好处。

### 优势为负：这个动作应该抑制

概率比从 1 降到 0.9 是合理修正；降到 0.8 仍在边界；降到 0.5 时，裁剪阻止优化器因为一条坏经验把动作概率几乎删光。

## 4. 为什么同一批经验可以训练多轮？

REINFORCE 常把一批轨迹用一次就丢掉。PPO 保存采样时的旧对数概率，对同一批数据做多个**训练轮次（Epoch）**：

1. 用旧策略收集一批状态、动作、奖励；
2. 计算一次优势和旧动作概率；
3. 打乱成小批次；
4. 更新策略；
5. 用新概率除以保存的旧概率；
6. 只要变化仍受限制，就继续利用这批经验。

它像同一套练习题做多次订正，但每次都对照“第一次作答时的思路”，防止订正到完全偏离原题。

::: warning PPO 仍是同策略方法
**同策略方法（On-Policy Method）**依赖当前或非常接近当前策略的数据。裁剪让一批数据能有限复用，不代表它能像 SAC 一样长期使用几万步以前的任意旧经验。
:::

## 5. 怎样知道限速器是否经常介入？

训练常记录两个诊断量：

- **裁剪比例（Clip Fraction）**：样本中有多少概率比超出裁剪区间。
- **近似 KL 散度（Approximate Kullback-Leibler Divergence）**：新旧策略分布整体变化多大。

如果裁剪比例长期接近 0，更新可能过于保守；如果接近 1，说明大量样本都想冲出边界，学习率或训练轮次可能太大。

KL 散度不是奖励，也不是策略损失。它更像仪表盘上的“方向盘转动幅度监控”。

## 6. PPO 的完整损失有哪些部分？

通常包含：

`总损失 = 策略损失 + 价值系数×价值损失 - 熵系数×策略熵`

- 策略损失使用裁剪目标；
- 价值损失训练评论家；
- 熵奖励保留探索；
- 梯度裁剪防止极端批次产生过大更新。

这些“裁剪”不要混淆：概率比裁剪限制策略变化；梯度裁剪限制参数梯度长度；动作裁剪限制环境动作范围。它们解决的不是同一个问题。


<div class="algorithm-box">

**算法：PPO 一次完整迭代**

1. **采样**：用当前策略 $\pi_{\text{old}}$ 并行收集一批 $T$ 步数据（状态、动作、奖励、旧对数概率）。
1. **估计**：用评论家算 GAE 优势 $\hat A_t$ 和回报目标 $\hat R_t$（第 8 课）。
1. **多轮更新**：重复 $K$ 个 epoch（如 10）：打乱数据成小批次，每批计算总损失 = 裁剪策略损失 + 价值系数 × 价值损失 − 熵系数 × 熵。
1. **监控**：每批记录裁剪比例与近似 KL；KL 超阈值（如 0.02）时提前停止本批（早停是常见工程保护）。
1. 丢弃这批数据，回到第 1 步——同策略方法不能用旧数据无限训练（第 18 课）。

</div>

## 7. 对应的可运行代码

核心位于 `src/rl_learning_lab/ppo.py`：

```python
new_log_probabilities = distribution.log_prob(actions)

# 在对数空间先做减法，再指数还原，比直接除很小概率更稳定。
probability_ratio = torch.exp(new_log_probabilities - old_log_probabilities)
unclipped = probability_ratio * advantages
clipped = torch.clamp(
    probability_ratio,
    1.0 - config.clip_coefficient,
    1.0 + config.clip_coefficient,
) * advantages

actor_loss = -torch.minimum(unclipped, clipped).mean()
critic_loss = torch.nn.functional.mse_loss(state_values, return_targets)
loss = actor_loss + 0.5 * critic_loss - 0.001 * distribution.entropy().mean()
```

## 9. PPO 适合什么场景？

PPO 常用于：

- 离散或连续动作控制；
- 能并行运行许多仿真环境；
- 更看重训练稳定和实现清晰，而不是极致样本效率；
- 机器人仿真、游戏控制和大模型对齐中的策略优化。

如果真实环境交互非常昂贵，希望每条旧经验长期复用，SAC、TD3 等异策略算法通常更合适。

## 10. 常见误区

- **裁剪保证绝对不退步。** 它是经验上稳定的近似限制，不是严格单调改进证明。
- **概率比裁剪等于把神经网络参数裁剪。** 它裁的是样本目标中的概率比。
- **训练轮次越多越好。** 轮次过多会让策略在同一批数据上走得太远。
- **优势为负时仍应取较大的目标。** PPO 统一取两个代理目标中的较小值，负数情况下更容易混淆。

## 11. 动手练习

1. 把裁剪系数从 0.2 改成 0.05，观察学习是否更慢。
2. 把训练轮次翻倍，观察裁剪比例和近似 KL 是否升高。
3. 暂时把裁剪系数改成 10，比较训练稳定性。

## 13. 本课只需要记住这些

- PPO 用新旧动作概率比衡量策略变化。
- 裁剪让过大的有利更新不再获得额外收益。
- 一批经验可以训练多轮，但仍不能无限期复用。
- 裁剪比例和近似 KL 是监控更新幅度的重要仪表。
