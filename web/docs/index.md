## 课程不是“算法名词展览”

这套课程始终围绕一个问题推进：**智能体怎样从试错中得到更可靠的决策规则？**

- 第 0 课先打地基：MDP、贝尔曼方程与动态规划——后面所有算法都在解同一组方程。
- 第 1—4 课认识状态、动作、奖励、价值、策略和优势，从 Q 表走到行动者—评论家。
- 第 5—7 课解决策略更新过猛、连续动作和旧经验复用问题。
- 第 8—12 课像修理工具箱一样，逐个修复 DQN 的常见薄弱点。
- 第 13—17 课把视野扩展到连续控制、规划、多个智能体、固定数据集和真实部署。
- 第 18—21 课补全拼图：蒙特卡洛与 SARSA、探索方法、模仿学习与 RLHF、调试指南。
- 如果你准备面试强化学习岗位，先看[强化学习岗位面试路线](/interview/)：它把 15 个高价值问题映射到对应章节、公式手算、代码实验和常见追问。

::: tip 推荐学习节奏
每课先读“旧方法哪里卡住”，再操作实验台，然后手算一个例子，最后运行代码。一天一课比一次读十课更有效。
:::

## 开始之前只需要知道三件事

1. **强化学习不是监督学习。** 环境不会告诉智能体“标准动作”，只会给结果分数。
2. **奖励不是命令。** 奖励只说明结果好坏，智能体仍要自己发现哪些动作导致了结果。
3. **训练曲线波动很正常。** 智能体必须探索，随机策略和随机环境都会让单局成绩上下起伏。
